# Otherwise 0.4 — The Available Witness / The First Human

The governing question is whether losing the service makes accepted presence disappear. This generation adds a separate four-witness reference profile, a disposable Laravel consumer client, an owner CLI and a design-only correspondence comparison. All content is synthetic; delivery remains simulated.

Required separations: protocol / product; signed evidence / product projection; policy authorisation / cryptographic custody enforcement; message semantics / transport. PorterNet is neither implemented nor required. Earlier generations and their counterexamples remain in their original directories.

The bounded implementation supports a static committee, finite schedule (up to eight slots), P=3/A=3/f=1, immutable owner-signed manifests, independent receipt retention, same-identity authenticated witness repair and owner-signed quorum disarm. This is not dynamic-membership Byzantine consensus, perpetual scheduling, production custody or independent-host validation.

The product demonstrates encrypted creation → export recovery kit → arm → check in → verify acknowledgement → inspect evidence → miss a window → evaluate and simulate release; an independent branch demonstrates disarm before closure. The disappearing-SaaS experiment removes Laravel, its PostgreSQL database **and** the adapter, then exercises the exported owner capability directly.
