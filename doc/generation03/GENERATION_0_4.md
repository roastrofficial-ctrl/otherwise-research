# Proposed Generation 0.4 — The Available Witness

The 0.3 result is useful precisely because its cost is visible: two receipts can protect a creator against one dishonest witness, but release requires all three. A silent signer can withhold disclosure forever. The next generation should test availability without losing retained-presence safety.

1. **Try a static four-witness committee with P=3/A=3/f=1.** Its quorum overlap exceeds f, while three responsive honest witnesses can progress if one refuses or crashes. This is only a candidate, not an implemented or proven consensus system. Test overlapping partitions, receipt loss and equivocators. Do not imply tolerance of an additional simultaneous crash beyond the tested budget.
2. **Specify repair before rotation.** A quarantined/identity-lost member cannot simply return with empty state. Define authenticated state transfer, retained checkpoint selection, recovery certificates and how an old membership prevents conflicting replacement committees. Preserve every fork and never silently reset a challenge.
3. **Distribute creator receipts directly.** Test mobile-side durable receipt caches and asynchronous delivery to independent observers/custodians. Study which proof survives an app crash and an unavailable malicious issuer without turning every check-in into all-to-all traffic.
4. **Separate finalisation from delivery ordering.** The current compact proof gives permission for a fixed operation but no globally unique certificate hash or exactly-once delivery. Specify idempotency on operation identity, disarm races after partial closure and delayed custody responses. Keep irreversible capability release explicit.
5. **Test real independent infrastructure and clocks.** Separate administrative domains, authenticated encrypted transport, process/host restarts, slow storage and real packet partitions. The current partition schedule is controlled message reachability; the clock/host assumptions still matter. Remove administrative fault routes from any deployment build.
6. **Expand the proof corpus and workloads.** Generate validity-preserving adversarial histories and faults across memberships; shrink actual mismatches. Measure WAN timeout tails, cold storage, repeated schedules, repair storage and larger policy graphs. The current local sample sizes and percentile estimates are only an initial cost envelope.

Keep the Solo interaction one human action with a verifiable acknowledgment. Do not expose committee management as a requirement for ordinary users. Continue to use synthetic recipients, and retain the malicious-custody-quorum limitation rather than assuming more witnesses solve possession of shares.
